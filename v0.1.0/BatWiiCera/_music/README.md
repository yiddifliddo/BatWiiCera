# BatWiiCera - background music folder

Drop any `.mp3`, `.ogg`, `.wav` or `.flac` files in this folder and enable
**Background music** under *Main Menu > UI Settings > Theme Configuration*.
EmulationStation will shuffle through every track it finds here while you browse.

No audio is shipped with the theme. Nintendo's original console menu music is
copyrighted, so it is not included and must not be committed to this repository.
If you own a copy, place it in this folder on your own device only.
